# Skills de design

Skills de design frontend issus de [taste-skill](https://github.com/Leonxlnx/taste-skill)
(licence MIT, voir `LICENSE-taste-skill`).

| Skill | Usage |
| --- | --- |
| `design-taste-frontend` | Skill principal : landing pages, portfolios, refontes — évite les designs génériques |
| `redesign-existing-projects` | Auditer et améliorer un site existant sans casser le fonctionnel |
| `high-end-visual-design` | Typographie, espacements, ombres et animations de niveau agence |
| `minimalist-ui` | Style éditorial épuré, monochrome chaud, grilles bento |
| `industrial-brutalist-ui` | Style brut, grilles rigides, contrastes typographiques extrêmes |
| `full-output-enforcement` | Interdit les sorties tronquées ou les placeholders dans le code |

Les skills du dépôt d'origine qui dépendent de la génération d'images
(`brandkit`, `imagegen-frontend-web`, `imagegen-frontend-mobile`,
`image-to-code`) ou d'autres outils (`stitch-skill` pour Google Stitch,
`gpt-tasteskill` pour Codex) ne sont pas installés ici.
